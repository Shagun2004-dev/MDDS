# 🩺 **Multie-Disease Diagnostic System (Heart Disease & Breast Cancer Prediction)**

## 📌 **Overview**

This project is a **Machine Learning–based Disease Diagnostic System** that predicts the likelihood of **Heart Disease** and **Breast Cancer** using patient medical data.
It uses classification algorithms to assist early diagnosis and support healthcare decision-making.

---

## 🚀 **Features**

* ✔ Predicts **Heart Disease** based on key risk factors
* ✔ Predicts **Breast Cancer** from tumor features
* ✔ User-friendly interface (Flask)
* ✔ Data preprocessing & feature engineering
* ✔ Trained ML models (Logistic Regression, Random Forest, etc.)
* ✔ Visualizations and performance metrics
